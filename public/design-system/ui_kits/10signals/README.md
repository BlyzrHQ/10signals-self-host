# 10 Signals — UI kit

Click-through recreation of the 10 Signals product surfaces, composed from `components/`:

- `Landing.jsx` — hero, domain input, three pillars, pricing (launch targets).
- `Progress.jsx` — live run with ProgressPhases; auto-opens the report.
- `Report.jsx` — decision header, tabs (Competitors / Products / Benchmark + Planned tabs), competitor dossiers, By-product and Table views with competitor filter and feedback thumbs, benchmark tracks.
- `SignIn.jsx`, `Account.jsx` — planned account surfaces: reports, plan & usage, profile, API keys, connected apps.

Open `index.html`; the strip at the top switches screens. Data is fictional (lumenandoak.com). The landing explainer animation lives in the prototype (`10 Signals.dc.html`) and is shown as a slot here.
