# 10Signals public source rules

- Preserve uncommitted user changes. Do not commit credentials or local data.
- This is a self-hosting preview, not a production-ready release.
- Keep public-source facts, inferences, estimates and recommendations distinct.
- Use fixture data only in clearly labeled tests or UI examples.
- Validate real-data claims against a real public source; never launch paid
  research without user authorization.
- Run relevant tests, lint and build checks before proposing changes.
- Contributions are reviewed and integrated by maintainers; do not attempt to
  access private infrastructure or automatically publish/deploy from this copy.
