The evidence-state pill: glyph + fill style + text, so a claim's provenance is readable without color.

```jsx
<EvidencePill state="observed" />
<EvidencePill state="inferred">Region: US (shipping page)</EvidencePill>
<EvidencePill state="limited" uppercase>Limited</EvidencePill>
```

Also used as the report status tag (observed→"Complete", limited→"Limited"). Never invent a fifth state.
