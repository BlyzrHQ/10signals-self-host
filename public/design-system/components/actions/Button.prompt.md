Outlined pill button; primary is a blue outline (10 Signals has no solid-filled button), used for the main action on a screen.

```jsx
<Button>Run report</Button>
<Button variant="secondary">Export CSV</Button>
<Button variant="ghost" size="sm">Sign out</Button>
```

Sizes sm/md/lg (lg = 46px hero input height). `block` stretches to full width. Disabled drops to 45% opacity.
